# 前台操作小抄

> 前台只用**鍵盤**。開始前先按 **F** 全螢幕，再按 **?** 確認狀態列寫著「素材已就緒 ✓」，名單版本跟後台控制台一樣，再按一次 **?** 關掉。

## 基本按鍵

| 按鍵 | 功能 |
|---|---|
| **→**、**空白鍵**、**PageDown** | 下一頁、開始滾動、停下抽出（三個都一樣） |
| **←**、**PageUp** | 上一頁；在主頁時回看已完成的獎項 |
| **X** → 數字 → **Enter** | 作廢第幾格（**0** 是第 10 格，**Esc** 取消） |
| **B** | 黑畫面（再按一次回來） |
| **F** | 全螢幕 |
| **?** | 按鍵說明與狀態列 |

## 一個獎項的流程

```
主頁 →（按）獎項頁 →（按）抽獎頁，格子開始滾動 →（按）停下 → … →（按）回主頁
```

- **每一次抽獎都按兩下**：第一下開始滾動，第二下停下。主持人可以喊「三、二、一」再按停。
- **一次抽完**：一按停下，全部格子從第 1 格依序停下。
- **逐個抽出**：每一格都是「開始、停下」各按一次。
- 全部停下之後再按一次，回到主頁，自動接到下一個獎項。
- 動畫進行中按什麼都沒反應，這是正常的。

## 現場狀況

| 狀況 | 怎麼做 |
|---|---|
| 得獎人不在場，主持人宣布放棄 | **X** → 格子號碼 → **Enter**，格子變淡並標示「作廢」→ 按 **→** 開始滾動 → 再按 **→** 停下補抽 |
| 作廢的人在補抽前趕回來 | 對同一格再做一次 **X** → 號碼 → **Enter**，恢復原得獎人 |
| 已經回到主頁，才發現有人要作廢 | 主頁按 **←** 回到剛剛的獎項，照上面作廢補抽。**下一個獎項開抽後就不能再改** |
| 主持人要求先抽別的獎項 | 請後台改「下一個要抽的獎項」，回到主頁就會接上 |
| 要暫時遮住畫面 | **B** |

## 看到這些時

| 畫面 | 怎麼做 |
|---|---|
| 右下角「離線中，待同步 N 筆」 | 網路斷了。**繼續抽，不要關掉、不要重新整理**，網路恢復後會自動補上 |
| 右下角有一個小灰點，按鍵沒反應 | 用滑鼠點一下畫面 |
| 抽獎頁按 F5 跳出「不能重新整理」 | 正常。真的要重新整理，先回到主頁 |
| 主頁按 → 顯示「名單載入中」很久 | 通知後台 |
| 上方紅色提示 | 照提示做，或通知後台 |
| 整個畫面「另一台前台作用中」＋4 位數代號 | 把代號告訴後台 |
| 電腦當機 | 用備用電腦打開前台連結，把畫面上的 4 位數代號告訴後台 |
