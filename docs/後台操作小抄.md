# 後台操作小抄

> 打開 Sheet，先看「控制台」分頁的**目前狀態**和**下一步**，照著按就對了。
> 所有按鈕都在上方選單「**摸彩系統**」裡。第一次按會跳出授權畫面，屬正常現象。

## 三原則

1. **不刪列**：要移除的人，把「登錄狀態」改成「移除」
2. **不排序**：找人用「篩選」
3. **新增一律加在最下面**

## 活動流程

| 什麼時候 | 按什麼 |
|---|---|
| 開放報到 | 活動當天 › **開始報到** |
| 報到時間到了 | 活動當天 › **截止報到** |
| 截止後、要開始抽獎前 | 活動當天 › **鎖定名單**，再請前台重新整理 |
| 全部抽完 | 活動當天 › **結束活動** |
| 要列印得獎名單 | 活動當天 › **整理得獎名單**，再按 Ctrl+P |

## 現場狀況

| 狀況 | 怎麼做 | 什麼時候可以做 |
|---|---|---|
| 名單上沒有的人到場 | 「人員」分頁最下面加一列，填單位、工號、姓名、可否摸彩，登錄狀態選「現場新增」，請他自己掃 QR code | 截止報到前 |
| 截止後才到、名單上沒有 | 同上，再點他那一列的「報到時間」，按 **Ctrl + Shift + ;** | 鎖定名單前 |
| 名單上的人不該參加 | 「登錄狀態」改成「移除」 | 鎖定名單前 |
| 幫錯人報到了 | 把那個人的「報到時間」清空 | 鎖定名單前 |
| 獎項要加碼或改數量 | 直接改「獎項」分頁 | 截止報到前 |
| 要先抽別的獎項（貴賓還沒到） | 控制台「下一個要抽的獎項」黃色格子，從下拉選單選 | 隨時，前台回主頁時生效 |
| 鎖定後才發現漏了人或獎項要改 | 活動當天 › **解除鎖定** → 修改 → 再按 **鎖定名單** | 前台還沒抽出第一位之前 |

## 看到這些時

| 畫面 | 意思 | 怎麼做 |
|---|---|---|
| 「現在不能○○，下一步請按…」 | 按錯順序了 | 照提示按 |
| 「沒有鎖定，有 N 個問題要先處理」 | 名單或獎項有錯 | 看控制台右側「資料檢查結果」，改好再按一次 |
| 控制台「獎項在鎖定後被修改」 | 鎖定後有人動了獎項 | 解除鎖定 → 重新鎖定 |
| 控制台「最後回報時間」變紅 | 前台可能斷線 | 問前台操作員；前台斷線時可以繼續抽，連回來會自動補上 |
| 控制台「最近 10 分鐘錯誤」變紅 | 系統有錯誤 | 通知系統管理者 |

## 彩排完

進階 › **清除資料** → 輸入「確定清除」。人員名單、獎項、設定都會保留。
