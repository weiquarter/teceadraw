# 活動前檢查清單

## 系統管理者（活動前一週內）

- [ ] 壓力測試已通過
- [ ] 「活動前 › 初始化」按「檢查」通過，**沒有**「部署的版本比目前的程式舊」的提醒
- [ ] Sheet「檔案 › 設定 › 計算」是「變更時和每分鐘」
- [ ] 「活動前 › 資料檢查」沒有錯誤；提醒都看過（特別是罕用字、找不到照片）
- [ ] 每位後台操作員都已在彩排時按過選單、完成授權
- [ ] 彩排資料已清除，控制台「目前狀態」是「準備中」

## 承辦人

- [ ] 報到 QR code 已列印（「活動前 › 產生連結」下載 PNG），放在入場桌上
- [ ] 前台和後台的操作小抄已印出（後台小抄含三原則：不刪列、不排序、新增加在最下面）
- [ ] 主持人說明規則：「唱名後沒上台，就視為放棄」（等待時間由主持人判斷）
- [ ] 主持人、前台、後台的溝通方式已約定；口令順序：主持人唱名完 → 前台作廢都按完 → 主持人才說下一個獎項

## 前台電腦

- [ ] 插電、關閉通知、暫停 Windows 更新、關閉螢幕保護
- [ ] 投影解析度與全螢幕確認（按 **F**）
- [ ] 鎖定名單後，前台已在主頁按 F5 重新載入，**名單版本跟控制台一致**（前台按 **?** 看）
- [ ] 前台狀態列顯示「素材已就緒 ✓」
- [ ] 控制台「前台監看」有前台代號，「最後回報時間」持續更新

## 備用電腦

- [ ] 能打開前台專屬連結，畫面顯示「另一台前台作用中」與接手代號（代表連結有效、可以接手）
- [ ] 確認後關掉，**不要**讓兩台同時開著
- [ ] 前台電腦已下載並解壓縮雲端硬碟的「【備用】前台本機版」，版本跟後台程式一致（GitHub Pages 連不上時使用）
